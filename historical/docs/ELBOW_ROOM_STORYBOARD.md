## Overview

This animation reveals the **rare "elbow events"** where membrane prime constructions benefit from zero-padding expansion as the middle length (M) grows. These events expose honorary zero dynamics—the interplay between symmetry, divisibility, and prime density around the midpoint axis.

**Key Message**: Elbow events are **rare exceptions** that prove the rule: k*=0 universality dominates, but structured pockets in parameter space reveal local elbow room dynamics.

**Frame Divisions**:
- Top 15%: Titles and headers

## Animation Principles

### Timing
- **Fast actions**: 0.5-1.0s (fades, simple transitions)
- **Medium actions**: 1.0-2.0s (bar morphs, complex transitions)
- **Slow reveals**: 2.0-3.0s (explanations, context)

### Easing
- **Fade in/out**: Linear or slight ease-in-out
- **Bar growth**: Ease-out (rapid start, gentle finish)
- **Morphs**: Smooth cubic interpolation

### Consistency
- All fades use same duration (0.5-1.0s)
- All bar charts use same color mapping function
- All text uses same font family

## Technical Notes

### Data Flow
1. **Extract**: Run `cargo run --example extract_elbow_events`
2. **Generate**: Creates `elbow_events.json`
3. **Render**: Manim reads JSON and generates animation
4. **Output**: `media/videos/manim_elbow_room/*/ElbowRoomComplete.mp4`

### Error Handling
- If no events detected → "No elbow events" scene (3s static)
- If JSON missing → Script exits with helpful message
- If event data malformed → Graceful skip with warning

### Customization

**Change event focus**:
```python
# In manim_elbow_room.py
class ViewSingleEvent(Scene):
    event_index = 0  # Change to 1, 2, etc.
```

**Adjust colors**:
```python
# Modify ElbowColors class
DENSITY_PEAK = "#your_color_here"
```

**Change duration**:
- Edit `run_time` parameters in each `self.play()` call
- Recommended: Keep total under 25 seconds for attention span

## Accessibility

### Color Blindness
- Teal/blue/yellow palette is deuteranopia-friendly
- Red/mint contrast works for protanopia
- Avoid relying solely on color (use labels, position, size)

### Text Legibility
- Minimum font size: 16pt at 1080p resolution
- High contrast ratios (4.5:1 minimum)
- Avoid thin fonts (<400 weight)

### Animation Speed
- No flashing or strobing (epilepsy risk)
- Transitions smooth enough to follow (no jarring jumps)
- Option to pause/replay (video controls)
