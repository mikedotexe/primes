# Agda Resources

This is a curated reference list for contributors working in the Agda subtree.
It is a resource catalog, not a roadmap or current status report.

## Core References

- [Agda language documentation](https://agda.readthedocs.io/en/latest/)
- [Agda standard library v2.3](https://agda.github.io/agda-stdlib/v2.3/)
- [agda-unimath elementary number theory](https://unimath.github.io/agda-unimath/elementary-number-theory.prime-numbers.html)
- [Doisinkidney: Primes in Agda](https://doisinkidney.com/posts/2018-12-14-primes-in-agda.html)

## Why These Matter Here

- stdlib references help resolve import and proof-style issues in the current
  workspace
- agda-unimath is relevant for future number-theory strengthening where the
  repo still relies on postulates or executable checks
- practical prime-formalization examples are useful when converting sketches
  into hole-free proofs

## Use With Caution

- this file does not imply the repo already depends on or integrates every
  linked resource
- for current local proof status, use [`STATUS.md`](STATUS.md)
- for local toolchain troubleshooting, use [`FIX_IMPORTS.md`](FIX_IMPORTS.md)
