Lagrange Point Explorer Help

This tool visualizes membrane primes with symmetric zero-padding.

Real Examples:

Config (3,3) k=(1,1) base 10:
303050303 = 3-0-3-0-5-0-3-0-3 ✓ PRIME

Config (3,7) k=(1,1) base 10:

The zeros are actual padding between membrane layers.

Commands:

  • g - Generate new prime pair
  • t - Test Lagrange points for primality
  • c - Cycle through configurations
  • ← → - Select prime atom
  • h - Toggle this help
  • q - Quit (refresh page)
