Web TUI Test

Open index.html in a web browser to see the interactive TUI.

Features:

  • Press 'g' to generate prime pairs
  • Press 't' to test Lagrange points
  • Press 'c' to cycle configurations
  • Press 'h' for help
  • Arrow keys to select prime

To serve locally:

cd prime-physics-engine/web-tui
python3 -m http.server 8000
# Then open http://localhost:8000
