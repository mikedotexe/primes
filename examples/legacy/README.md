# Legacy Examples

This directory contains examples that are preserved for historical reference but are not actively maintained.

## Directory Structure

- `broken/` - Examples with compilation errors that would require significant refactoring
- `duplicates/` - Alternative versions of examples that have been consolidated
- `visualization/` - Pure visualization examples with heavy Unicode/ASCII art

## Why These Are Legacy

These examples represent the evolution of the project but are not suitable for:
- New users learning the core concepts
- Automated testing and CI/CD
- Documentation and tutorials

## Heritage Value

These examples document:
- The exploratory phase of development
- Alternative approaches that were tried
- Visual presentation experiments
- Complex demonstrations that pushed the boundaries

## Usage

These examples are **NOT guaranteed to compile** and should be used only for:
- Understanding the project's evolution
- Mining ideas for future development
- Historical reference

For working examples, see the main `examples/` directory.
