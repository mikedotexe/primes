# Archive

This directory is for material that no longer meets the repository's current
public-facing scrutiny standard but is still worth preserving for context,
research history, or future salvage.

## Archive Criteria

Move a document here when one or more of these are true:

- the main claims are outdated enough that a simple edit would still leave the
  document misleading
- the document duplicates newer source-of-truth material and is likely to send
  readers down the wrong path
- the wording is strongly metaphorical or promotional in a way that obscures the
  actual current evidence
- commands, examples, counts, or file references are stale enough that the
  document is not practically usable without substantial repair

Do not archive material just because it is rough. Keep and revise documents that
still contain substantial signal, useful data, or a clear research narrative.

## Ground Rules

- Prefer rewrite over archive when the core content is still directionally
  correct and salvageable.
- If a document is archived, preserve its directory structure under `archive/`
  and add a short note at the top explaining why it moved.
- Update any user-facing links that pointed at the archived file.
- Treat `README.md`, `CLAIMS.md`, `NOVELTY.md`, `VERIFIED_FACTS_VS_SPECULATION.md`,
  and `agda-proofs/STATUS.md` as current source-of-truth candidates unless a
  newer audited document supersedes them.
