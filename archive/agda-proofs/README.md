# Agda Proof Archive

This directory preserves `agda-proofs/` narrative documents that still have
historical or research value but no longer meet the active-doc scrutiny
standard.

## Archived Here

- sprint plans and milestone schedules that no longer describe the current
  proof state
- progress/session summaries that were superseded by
  [`../../agda-proofs/STATUS.md`](../../agda-proofs/STATUS.md)
- theory pitches that use stronger novelty or universality language than the
  current repo evidence supports
- legacy README surfaces that were replaced by narrower status notes
